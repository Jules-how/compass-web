# Compass round two: structure before theme

Uses the UI Skills root and the registry's `dammyjay93/interface-design` reference, saved in `references/`. `emilkowalski/prototype` and `pbakaus/bolder` were inspected during routing: the former is explicitly invocation-only and the latter targets amplification of an already chosen design, so neither is adopted as the governing workflow. This round continues the user's broader exploration scope.

The reference's recommendations to reuse the existing visual system, keep sidebar and canvas colours equal, or ask before inexpensive exploratory changes are contextual preferences. Jules explicitly authorised a new visual language and more alternatives. This round stays isolated and uses the existing review harness rather than importing an unrelated picker or narrowing away the requested screens.

Human: Jules, solo operator, moving between review of the daily brief, campaign preparation and pending client decisions. Goal: make one useful move without treating waiting as active work. Feel: purposeful working software with a coherent visual identity.

Domain: enquiry, qualified appointment, preparation, factual opener, sequence, source evidence, client decision, verified handoff. Colour world: white copy paper, graphite notes, blue document ink, pale folder stock, teal equipment panels, yellow attention slips. These are original metaphors, not claims about Switchflow's physical office.

Signature: a campaign carries its preparation context from Home into the editor; review state is explicit, while waiting items keep their reason and source. No artificial scores or percentages.

Defaults challenged: dashboard hero plus three stat cards → task-specific layouts; universal list/detail split → handoff view, folder view and inline expansion; full-height library beside every editor → stage shelf, manuscript tools or two-email comparison.

## Relay
Axis: handoff-oriented workflow. Horizontal work navigation and a preparation path join daily brief, inventory, copy and handoff. Large readable action row, small supporting columns. Teal, acid yellow and white; Space Grotesk and DM Sans. 4px spacing basis, 32px canvas, 20px records. Reference language: dispatch sheet and handoff board, drawn as an original specimen.

Home focuses the brief above a preparation path. Inbox emphasises the case and its next action. Outbound separates next work from linked campaigns. Editor uses horizontal sequence steps, broad text area and an expandable preparation shelf. It wins when the day is about moving a campaign from decision to reviewed draft. Cost: the path must remain a projection of existing work, not introduce a rigid new process or new backend state.

## Folio
Axis: object-oriented desk. A pale lilac workspace and folder tabs keep the current brief/case/campaign as the persistent object. DM Sans controls with selective Newsreader titles. Soft depth only on the active document; 12px folder corners, 24px content padding, 4px spacing basis. Reference language: a working folder and annotated correspondence, drawn as an original specimen.

Home is a working brief with pinned waiting context. Inbox is a correspondence folder. Outbound is a campaign shelf. Editor is a manuscript with labelled margins and tools summoned when needed. It wins on long sessions of preparation, copy and planning. Cost: can feel too soft or document-like for fast bulk CRM operations; those need a disciplined dense record view.

## Index
Axis: register-oriented operation. Compact monochrome and cobalt, typographic index navigation, strong ruled rows and inline expansion. IBM Plex Mono metadata with Manrope content. 4px rhythm, 16px rows, 28px canvas, square geometry. Reference language: an operations register and technical document index, drawn as an original specimen.

Home puts the next decision directly inside the register. Inbox opens context beneath the selected row instead of occupying half the screen at rest. Outbound is a register with explicit preparation facts. Editor displays both actual emails side by side to compare the sequence as a whole. It wins on rapid scanning and comparison. Cost: less warmth; expressive rules must not overpower text or resemble a terminal.
