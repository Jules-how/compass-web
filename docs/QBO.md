# QuickBooks — historical integration

Jules stopped using QuickBooks on 8 September 2026. Do not use it for new-client signing, invoicing or expense tracking. Historical code and records remain available for reference, but the daily default sync no longer runs QBO.

New agreements use explicit reviewed terms and bank/Wise transfer or configured Stripe checkout. Compass tracks commercial status and expenses; payment receipt must come from provider/bank evidence.

The prior documentation is preserved in `archives/offer-transition-2026-09-08/compass-web/docs/QBO.md`. Its old prices and tax assumptions must not seed new work.
